# Данные

Справочники предметной области, досинтезированные данные и код, который превращает их в записи
для загрузки в мок учётной системы и в хранилище платформы.

## Структура

| Каталог | Содержимое | Правится |
|---|---|---|
| `reference/` | Справочники, выгруженные из шаблона доменных данных, по файлу на лист; public snapshot содержит синтетические значения, а `manifest.json` фиксирует генерацию и sanitization | Повторной выгрузкой с обязательной public sanitization |
| `reference/rules.yaml` | Машиночитаемая часть свода правил: категории по ADR-0004, условия срабатывания с уровнями, требуемая компетенция, сроки гарантии по W-01 | Вручную, с ревью: меняет `rules_version` |
| `synthetic/` | То, чего нет в справочниках, но без чего не работает сквозной сценарий: территории, внешние центры для регионов без мастерской, занятость инженеров, цены изделий, второй аппарат той же модели у одного партнёра (неоднозначность при определении по партнёру и модели, PRD 5.3) | Только генератором |
| `eval/nameplates/` | Снимки идентификационных табличек для набора оценки: читаемые с номером из справочника, читаемые с номером вне справочника, нечитаемые; `manifest.json` — ожидаемые значения | Только генератором |
| `demo/` | Демонстрация на настоящих фотографиях табличек: оборудование вносится вручную в `equipment_demo.csv`, фотографии в репозиторий не попадают (`demo/README.md`) | Вручную |
| `generators/` | `export_reference.py` — выгрузка справочников; `synthesize.py` — досинтез; `nameplates.py` — снимки табличек | — |
| `loader/` | `reference.py` — чтение справочников в типизированные записи с нейтральными полями и проверкой ссылочной целостности | — |

## Воспроизводимость

```bash
python data/generators/export_reference.py   # xlsx -> reference/*.csv
python data/generators/synthesize.py         # reference -> synthetic/*.csv
```

Оба генератора детерминированы: повторный запуск на тех же входах даёт побайтно те же файлы.
Шаблон `Шаблон_данных_проекта_s_3_региона.xlsx` в репозиторий не кладётся. В публичном snapshot
лежат только синтетические демонстрационные данные листов 01–06, 08–16, 18, 19. Исходные
клиентские записи, продуктивные данные и спецификация конкретного поставщика не включены.

## Текст правил не переписывается

Дословные поля правил — условие, решение, предписанные действия — хранятся только в
`reference/04_decision_rules.csv`. `rules.yaml` их не повторяет. Предписания возвращаются
пользователю в исходной формулировке (ADR-0004, раздел 5).

## Опоры обязательных сценариев

`tests/unit/test_reference_data.py` проверяет, что на этих данных воспроизводятся:

- гарантийное обращение по HP у петербургского партнёра, где собственная мастерская не
  авторизована по HP, внешний центр авторизован, а свободный собственный инженер L3 есть;
- отказ диспетчеру Москвы в доступе к оборудованию петербургского партнёра.
